# beep-bepp
(the name was actually beep beep. since this is submitted to stardance, lets roll with the imperfection)
beep bepp (beep beep)a hardware alarm device that was done under stardance projects.
# components used 
* XIAO ESP 32-C3 microcontroller (can be found at seeed website)
* buzzer
* push buttons (specifically 4) - got it from grab CAD. (kalia polih buttons)
* has four mounting holes at the corner. 
* TFT display
# .
**** softwares used
  
 * kiCAD - for designing the pcb and schematic layout for the circuit board to work
  
* onshape - for designing the case for the alarm
